상담과 제조사 조회

물질명 또는 CAS, 농도, 온도, 작업, 노출 조건을 입력하세요. 서로 다른 작업과 혼합액·동시 노출은 구분해야 합니다. DuPont 보호복 3종은 정확한 CAS로 공식 원단시험표를 조회하고, 나머지 품목은 등록 근거로 검토합니다. 해당 행 있음·행 없음·조회 실패를 구분합니다.

시험 조건의 돌파시간은 실제 착용 가능 시간이 아닙니다. 원단 성능은 완제품·연결부·전체 조합 승인과 다릅니다. 미확인 품목은 부분 조합의 남은 확인으로 보존합니다.

제품·사진·색상

인증 자료의 모델 연결과 현재 상태, 실제 판매 실물은 별도로 확인합니다. 공개 사용 근거가 확인되지 않은 제품 사진은 배포하지 않습니다. 도식은 품목 안내용이며 제품 실물이나 정확 모델 사진이 아닙니다. 카드의 색상 표시는 등록된 실제 판매 색상 정보입니다.

원본을 보유한 PC의 로컬 미리보기에서는 허용된 사진을 표시합니다. 사진의 원래 비율과 해상도를 유지하며 상세 화면에서 확대할 수 있습니다. 제품군 대표사진과 정확 모델 사진은 구분해 표시합니다. 이 로컬 사진은 공개 배포 파일에 포함되지 않습니다.

같은 작업의 대안은 같은 색을 사용할 수 있습니다. 다른 작업이나 사용 형식끼리 색상이 겹치면 충돌을 표시합니다. 색상을 위해 제품을 가상으로 만들거나 사진을 변색하지 않습니다.

초안과 개인정보

선택한 조합·근거·메모는 현재 브라우저에 저장되고 JSON으로 내려받을 수 있습니다. 조합을 편집하면 이전 추천 근거가 무효화됩니다. 승인·감지 등록·합성 생성 상태는 항상 false입니다.

상담 입력은 운영 서버와 모델 API로 전달됩니다. 회사 비밀이나 개인정보는 입력하지 마세요. 시연 코드는 브라우저 메모리에만 보관하며, 서버 대화는 임시 메모리에 유지하며 2시간 뒤 만료합니다. 만료된 대화는 다음 요청에서 정리합니다. 운영 서버를 재시작하면 대화가 초기화됩니다. 요청·토큰 예산 기록에는 상담 내용을 저장하지 않습니다.

에이전트 상담을 처리하는 동안 외부 서비스에 임시 대화가 생성됩니다. 요청 종료 시 삭제를 요청하고, 중단된 작업은 취소합니다. 외부 저장소의 실제 정리에는 시간이 걸릴 수 있습니다.
