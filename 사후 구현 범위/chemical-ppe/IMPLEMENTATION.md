- 실제 확인: 공개 브라우저에서 사진 없이 문장을 입력하고 코드 입력으로 이동해도 글이 보존됨을 확인했다. 가짜 시험 코드는 실제 401과 입력 보존을 확인했고 유료 호출이 없었다. 정상 코드로 ‘사진은 없는데 공장 세척용 보호복을 고르고 싶어요. 무엇부터 확인하면 될까요?’를 1회 전송해 Agents + Luna의 실제 응답을 받았다. 라벨 제품명을 글자로 알려 달라는 후속 질문 1개, 사진 미리보기 0개, 다음 보내기 활성화를 확인했다. 완료 후 미정리 Agents 세션은 0개다. 실제 화면·운영 확인 JSON은 Git 제외 .runtime/public-preview에 저장했다.
- 필요한 검사/범위: 기존 사진 흐름 검사에 사진 없는 새 대화 시작을 추가해 이미지 전달 없이 정상 응답·session 생성됨을 모의 확인했다. 해당 오프라인 검사, JS 구문 검사, 빌드, diff 공백 검사 통과 및 사전 기준선 8개 SHA256 일치. 실제 유료 상담은 위 가상 질문 1턴만 실행했다. 원본 사진·사전 코드·영상 관제 앱·다른 작업 변경은 보존한다.
- 남은 조건: 새로고침/다른 기기는 상담 시연 코드를 다시 입력해야 한다. 일일 요청/예약량·분당 제한과 6턴/대화 제한은 계속 적용된다. 사진 없는 실제 첫 답변을 확인했으며 다중 사용자 부하나 전체 상담 품질 평가로 일반화하지 않는다.


## 방문자 코드 없는 공개 상담 시연 (2026-10-09)

- 사용자 확정: ‘접속해서 시연하게’, ‘코드없이’라는 최신 지시에 따라 기존 시연 코드 입력 단계를 현재 공개 홈페이지에서 제거한다. 이전 기록의 재입력 요구는 코드 사용 모드에만 해당한다.
- 구현: 서버 Settings에 PPE_REQUIRE_DEMO_CODE(기본 true)를 추가했다. false이면 준비 상태에서 시연 코드를 요구하지 않고 상담 경로의 방문자 토큰 검사를 생략한다. 상태 API의 access_required=false를 읽은 화면은 코드 패널을 숨기고 새 방문·새로고침부터 전송을 활성화하며 Authorization 헤더를 보내지 않는다. 키나 시연 코드를 프런트엔드에 넣는 방식은 사용하지 않았다.
- 운영: 현재 로컬 .env에 PPE_REQUIRE_DEMO_CODE=false를 적용했다. 미정리 Agents 세션 0개 확인 후 홈페이지 서비스만 재시작해 공개 주소를 유지했다. 기존 서버 API 키·모델·일일 예약량 300만·일일 요청 30회·분당 4회·동시 상담 1건·본문 제한·STOP 중지를 유지했다. 공개 모드에서는 허용 Origin을 요구하고 누락/다른 Origin을 거절하지만 Origin을 사용자 인증으로 표현하지 않는다.
- 실제 확인: 공개 HTTPS 상태 ready=true/access_required=false와 등록 사진 44개를 확인했다. Authorization 없는 비JSON 요청은 인증 단계를 지나 415, Origin 없는 요청은 403이었다. 새 브라우저 탭에서 어떤 코드도 입력하지 않고 사진 없는 가상의 초보자 세척 질문을 전송했다. Agents + Luna 답변과 제품명 요청 질문 1개를 받았고 코드 패널 숨김·첨부 0개·다음 보내기 활성화를 확인했다. 추가 새로고침 후에도 ‘바로 상담할 수 있어요’와 활성화된 보내기를 확인했으며 두 번째 유료 전송은 하지 않았다.
- 검사: 짧은 공개 접근 검사에서 기존 코드 모드 401, 코드 없는 모드 200, 다른/누락 Origin 403, 요청 한도 429, STOP 503, 종료된 터널 Origin 403, 등록 사진 격리를 확인했다. 오프라인 유료 호출 0회. 빌드/JS 구문/diff 검사 통과, 사전 기준선 SHA256 8개 일치. 실제 상담은 위 1턴만 실행했고 완료 후 미정리 Agents 세션 0개다. 개인 확인 JSON/스크린샷은 .runtime/public-preview에만 저장한다.
- 남은 조건: 현재 주소에 접속한 누구나 서버 예산을 함께 사용하는 시연이다. 기존 호출/시간/예약량 제한이 소진되면 상담은 중지될 수 있다. 실제 청구액의 상한 보장이나 다중 사용자 부하 시험 완료를 주장하지 않는다. 공개 터널의 PC 의존·임시 주소 조건도 유지한다. 사전 자료/사진 원본/관제 앱/다른 작업 변경은 보존했다.
