# 화학보호구 홈페이지 구현 기록

작성: 2026-10-09. 기준: 사전 `03_화학보호복_페이지_PRD`의 H01–H05와 기준선 SHA256.

## 기존 성과와 이번 변경

사전 페이지의 44개 제품·150개 출처·43개 국내 구매/견적 경로, 검색·필터, 수동 조합, 작업/형식별 색상 구분, 초안 저장·복원·JSON, 상담 지침/스키마, DuPont 3종의 CAS 조회를 재사용했다. 사전 원본 8개 파일은 그대로 보존했다. 기존 상담 서버의 CodexClient는 실행하지 않는다.

이번 화면은 사용자가 사진과 모델명을 먼저 보고, 상세 정보를 필요할 때 열도록 다시 구성했다. 사진 카드 → 상세·확대 → 최대 3개 비교 → 내 조합 순서로 사용할 수 있다. 제품군 대표사진과 모델 연결 사진, 등록된 실제 색상, 구매 경로와 미확인 사항을 구분한다. 사진은 자르거나 변색하지 않는다. 모바일에서는 필터·제품 카드·상세 창을 화면 폭에 맞춰 배치한다.

기존 단일 스크립트를 역할별로 분리했다. `core.js`는 기존 공통/근거 함수, `drafts.js`는 기존 조합·초안, `bootstrap.js`는 기존 초기화의 수정본이다. `catalog.js`는 새 제품 탐색 화면, `counselor.js`는 새 Responses 연결이다. 파생 코드는 사후 폴더에 두고 파일 머리에 재사용 출처를 명시했다.

서버는 Responses로 CAS 계획과 최종 상담을 요청하고 그 사이에 기존 제조사 조회를 실행한다. 등록 제품·출처 검증, 최대 3개 조합, 추가 질문, 시험 조건·원문 행, 실패 상태를 전달한다. 키·시연 코드, 호출/예약 토큰 제한, 중지 파일, 임시 대화를 별도 Python 서버에서 관리한다.
