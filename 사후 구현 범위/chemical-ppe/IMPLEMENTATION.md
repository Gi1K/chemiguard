## 후속 변경: Agents API 연결

2026-10-09 사용자가 키를 입력하고 Agents API 사용 및 Sol·Luna 연결 확인을 요청했다. 기본 연결을 `PPE_BACKEND=agents`, `OPENAI_MODEL=gpt-6-luna`로 변경했다. 원래 사전 지침·제품·출처 검증 및 CAS → 제조사 조회 → 조합 순서는 유지했다. 기존 Responses 경로도 명시적으로 선택할 수 있다.

- Sol(`gpt-6-sol`)·Luna(`gpt-6-luna`) 모두 모델 접근 200 및 Agents API의 실제 구조화 응답을 확인했다. 연결 확인용 세션은 각각 종료 후 삭제했다.
- Luna로 황산 30%·20°C 이송이라는 가상의 검증 사례 1건을 실행했다. 약 51.1초에 제조사 3종 조회, 검토용 부분 조합 2개, 추가 질문 2개를 반환했다. `approved=false`, 미정리 외부 세션 0개였다. 이는 연동 동작 확인이며 선정 품질 전체 검증이나 현장 승인이 아니다.
- 실제 완료한 Agents 세션은 연결 확인 2개 + 상담의 계획/최종 단계 2개다. 비용 설정이 거절된 초기 요청에서는 답변이 생성되지 않았다. 실제 청구 금액은 측정하지 않았다.
- 현재 계정은 세션 예산 필드에 `Session budget configuration is not enabled`를 반환했다. 따라서 `PPE_AGENT_BUDGET_ENABLED=false`로 명시하고, 요청·동시성·시간·예상 토큰 예약 제한을 사용한다. 금액 상한이나 Agents 출력 토큰 상한을 적용했다고 표시하지 않는다. 예산 기능 활성화 시에만 세션별 금액 제한을 선택할 수 있다.
- 세션은 sandbox·도구·하위 에이전트 없이 실행한다. 완료된 최종 답변만 받으며, 종료 시 세션 삭제를 요청한다. 실패·시간 초과 시 취소 후 삭제한다. 정리 전 ID만 로컬에 보관하고 재시작 후 다음 요청에서 처리한다. 삭제 실패 시 새 세션 생성을 중단한다.
- 오프라인 검사에 실제 OpenAI SDK의 SSE 파싱·초기 idle 무시·미완료 스트림 거부·취소/삭제 확인만 추가했다. 키·시연 코드·실제 응답 기록은 Git에 포함하지 않는다.

아래 표와 검증 기록은 최초 홈페이지 구현 시점의 상태다. 현재 H02의 실제 모델 연결 확인은 위 기록으로 갱신되며, 공개 HTTPS 배포와 공개 환경 검증은 아직 남아 있다.

## 기존 성과와 이번 변경

사전 페이지의 44개 제품·150개 출처·43개 국내 구매/견적 경로, 검색·필터, 수동 조합, 작업/형식별 색상 구분, 초안 저장·복원·JSON, 상담 지침/스키마, DuPont 3종의 CAS 조회를 재사용했다. 사전 원본 8개 파일은 그대로 보존했다. 기존 상담 서버의 CodexClient는 실행하지 않는다.

이번 화면은 사용자가 사진과 모델명을 먼저 보고, 상세 정보를 필요할 때 열도록 다시 구성했다. 사진 카드 → 상세·확대 → 최대 3개 비교 → 내 조합 순서로 사용할 수 있다. 제품군 대표사진과 모델 연결 사진, 등록된 실제 색상, 구매 경로와 미확인 사항을 구분한다. 사진은 자르거나 변색하지 않는다. 모바일에서는 필터·제품 카드·상세 창을 화면 폭에 맞춰 배치한다.

기존 단일 스크립트를 역할별로 분리했다. `core.js`는 기존 공통/근거 함수, `drafts.js`는 기존 조합·초안, `bootstrap.js`는 기존 초기화의 수정본이다. `catalog.js`는 새 제품 탐색 화면, `counselor.js`는 새 Responses 연결이다. 파생 코드는 사후 폴더에 두고 파일 머리에 재사용 출처를 명시했다.

서버는 Responses로 CAS 계획과 최종 상담을 요청하고 그 사이에 기존 제조사 조회를 실행한다. 등록 제품·출처 검증, 최대 3개 조합, 추가 질문, 시험 조건·원문 행, 실패 상태를 전달한다. 키·시연 코드, 호출/예약 토큰 제한, 중지 파일, 임시 대화를 별도 Python 서버에서 관리한다.

- 변경: `server.py`에 정확한 HTTPS Host + Tailscale 사용자 신원 + 실제 loopback 프록시 연결을 모두 요구하는 선택적 사진 미리보기를 추가했다. `run.sh`는 해당 설정에서 loopback 바인딩을 강제하고 Uvicorn의 전달 IP 헤더 처리를 끈다. `.env.example`, README와 이 폴더의 `AGENTS.md`에 재현 방법·범위를 기록했다. 실제 주소/계정과 기존 키는 Git에서 제외한 `.env`에만 둔다.
- 실제 확인: 앱 서버 재시작·production build 성공. 사전 SHA256 8개 일치, 제품 44개·공개 빌드 사진 0개. 실제 로컬 페이지와 사진 응답 성공. 허용한 프록시 신원을 모의한 요청은 사진 44개/이미지 200, 신원 누락·다른 사용자·다른 포트·전달 IP만 있는 요청은 목록 없음/404, loopback 이외의 직접 연결도 404. 허용 Origin은 인증 오류에 CORS 헤더를 반환하며 임의 Origin은 403. 기존 오프라인 계약 검사 통과, 유료 모델 호출 0회.
