# 화학보호구 카탈로그 작업 지침

- 이 디렉터리는 사용자가 별도로 요청한 카탈로그·상담 홈페이지의 사후 구현이다. 본선 저장소의 영상 감시 앱과 실행 프로세스는 별개이며, 감시 정책·Medium/Large·Luna Decisions를 변경하지 않는다.
- 사전 PRD·기준선 8개 원본은 `사전 구현 범위`에 보존한다. 파생 코드와 개선만 이 폴더에 기록하며 사전 성과를 신규 구현으로 바꾸지 않는다.
- 변경 근거·실제 확인·남은 문제는 `IMPLEMENTATION.md`에 누적하고, 본선 저장소의 `docs/DEVELOPMENT_LOG.md`에도 해당 작업의 위치와 상태를 기록한다. 다른 작업의 미커밋 변경을 함께 커밋하지 않는다.
- 2026-10-09 사용자 요청에 따라 원격 접속은 전용 포트의 비공개 Tailscale Serve로 연결한다. 기존 Serve/Funnel을 초기화하거나 공개 Funnel로 바꾸지 않는다.
- 로컬 원본 사진은 저장소·dist에 복사하지 않는다. 원격 미리보기는 명시한 HTTPS Host와 Tailscale 사용자 신원이 일치할 때만 허용하며, 서버는 loopback 바인딩과 `--no-proxy-headers`를 유지한다.
- API 키·시연 코드·Tailscale 로그인·개인 실행 근거는 `.env` 또는 `.runtime`에만 두고 공개 커밋에서 제외한다. 상담 모델은 기존 Agents API + Luna를 유지한다.
- 원격 접속 작업에서는 유료 모델 호출과 반복 벤치마크를 생략한다. 실제 확인한 로컬/HTTPS/원격 기기 결과를 구분한다.
