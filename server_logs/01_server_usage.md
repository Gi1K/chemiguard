## 수집·가명처리 방법

1. 기존 권한으로 `journalctl`의 `sshd`·`sshd-session` 식별자에서 위 시간 구간과 ACCOUNT_01의 성공 인증만 조회했다. 실제 16건 모두 공개키 인증이며 종료 코드 0, 표준 오류·권한 경고 없음이다.
2. 원본 ISO 8601 시각·결과·인증 방식·PID·포트를 유지하고 호스트·계정·출발 IP·키 지문만 SERVER_01·ACCOUNT_01·IP_01·KEY_01로 치환했다. 이전 수집본과 같은 별칭을 유지하며 IP 단순 해시는 쓰지 않았다.
3. 02는 사용자가 확인한 허용 사용자 목록이다. 03은 실제 성공 인증 발췌이며 04는 오직 03에서 중복 제거한 계정·출발 IP·프로토콜 목록이다. 네트워크 조회나 추정 IP로 행을 추가하지 않았다.
4. 본선 관련 4개 사용자 서비스와 명시한 Nginx 컨테이너만 상태 확인했다. 전체 사용자·프로세스·컨테이너 목록, 프로세스 인자, 환경변수, 전체 명령 이력, 비밀키·비밀번호·토큰·쿠키·환경 파일을 수집하지 않았다.
5. 원본·별칭 대응표·정확한 조회 명령·상태·무결성 해시는 저장소 밖에 보존한다. 이전 14:50:52 수집본과 갱신 전 공개 파일도 보존하며, 현재 server_logs/에는 지정 5개 가명 파일만 둔다.
