## 사전 구현과 오늘 구현의 구분

기존 감시 연구에는 CLI 사진 등록과 임베딩·SQLite 저장, 사람 검출·추적과 모델 비교, Pose 몸통 영역, 제품 외형 검색, 착용·가시성 관찰, TTL·관측 세대·늦은 응답 폐기, 별도 분출 모델 시험, 저장 분석 근거 재생과 사람 검토 기록이 있다. 확인된 구현과 실패·미검증 항목은 [PREWORK.md](02_감시_PRD_사전실험/PREWORK.md)에 기록했다.

기존 화학보호복 페이지에는 44개 제품 카탈로그, 물질 상담·제조사 근거 조회, 보호구 조합과 작업별 색상 비교, 브라우저 초안 저장·복원·JSON 내보내기가 있다. [페이지 PRD](03_화학보호복_페이지_PRD/page_rendered/CHEMICAL_PPE_PAGE_PRD_20261009.pdf)는 기존 구현과 H01~H05의 당일 목표를 구분한다.

새 감시 앱의 통합 분석·이벤트·화면 알림·업로드·새 DB, 실제 GPU/원격 실행·오류 검수·실측은 [감시 PRD](02_감시_PRD_사전실험/PRD.md)와 [아키텍처](02_감시_PRD_사전실험/ARCHITECTURE.md)의 당일 계획이다. 보호복 페이지의 공개 화면과 HTTPS 상담 API도 당일 계획이다. 기존 앱 전체, DB, 가상환경, API 키는 이 사전 자료 커밋에 포함하지 않는다.

## 모델과 저장 방식

기본 4종은 YOLO26l 사람 검출, YOLO26n-Pose, SigLIP2 모델 폴더, FASDD smoke YOLO26s다. 예비는 YOLO26s 사람 검출이다. 기본·예비 묶음은 설정·출처 파일을 포함해 12파일이며 [WEIGHTS.manifest.json](02_감시_PRD_사전실험/WEIGHTS.manifest.json)에 경로와 SHA256이 있다. 기존 `fasdd_yolo26s_leak_best.pt` 표시명 변경본도 별도 보관한다.

`.pt`와 `.safetensors` 가중치는 Git LFS로 추적한다. 실제 가중치는 LFS 업로드와 원격 무결성 확인이 끝나야 다운로드 가능한 상태다. 복제한 PC에서 `git lfs install`과 `git lfs pull`로 받는다.

영상 원본 152개는 사용자 요청에 따라 로컬에 보관한다. 저장소에는 영상 출처·상대 경로·크기·SHA256·기존 분석 기록이 남는다. `.gitignore`로 영상 파일 커밋을 제외한다. 영상 목록의 경로가 있다고 저장소에서 원본 영상이 제공되는 것은 아니다.

## 근거와 재현 범위

원래 DOCX·PDF, 과거 실험 수치·해시·출처 기록을 보존한다. 문서의 `/home/giwon/Downloads/...` 및 저장소 밖으로 나가는 근거 링크는 원래 PC의 사전 실험 위치를 뜻한다. 해당 외부 앱 소스·영상·DB 전체를 함께 공개했다는 뜻은 아니다.

파일 정리와 과거 측정값을 새 구현 성과로 세지 않는다. 실제 당일 구현·검수·시연은 이후 커밋과 실행 기록에서 별도로 공개한다.
