# 형식·작업별 보호복 색상 구분 (2026-10-07)

같은 3형식이라도 별도 관리 작업이면 보호복 색상을 구분하도록 구현했다. 같은 형식·같은 작업의 대체 조합은 같은 색이라도 작업 간 충돌로 보지 않는다. 공통 고정색이나 물질명 기반 규칙 엔진은 추가하지 않았다.

## 구현

- CatalogChat kit에 `work_group: string | null` 추가. 실제 작업 목적명을 사용하고 같은 작업의 대안과 기존 조합의 이름을 유지하도록 지시한다.
- 서버는 공백 정규화·80자 제한·빈 값 null을 적용하며, 사용 형식/작업 구분이 없으면 남은 확인에 기록한다. 중복 조합 signature에도 그룹을 포함한다.
- UI 카드와 내 조합에 작업 구분을 표시한다. `selected_work_group` 저장/복원, 추천 문맥의 `existing_kits.work_group`, 편집 시 추천 근거 무효화를 연결했다. 이전 초안은 없는 그룹을 추정하지 않는다.
- 색상 비교는 저장 조합과 현재 추천 모두에서 진행한다. 다른 형식 또는 같은 형식의 서로 다른 알려진 작업 그룹끼리 같은 색이면 충돌을 표시한다. 형식·그룹·색상 미상은 확인 전이다.
- 모델은 물질·농도·온도·노출·부품 연결 근거를 먼저 검토한다. 다른 색의 근거 있는 제품이 없으면 충돌·대안 미확인을 남긴다. 사진 변색과 없는 색상 SKU를 만들지 않는다.
- 혼합액·동시 노출은 공통 작업 그룹으로 검토하도록 지시했다. 산용·알칼리용 두 조합이나 순물질 시험의 교집합을 혼합액 적합성으로 확정하지 않는다. 이 분기의 새 실제 상담 테스트는 이번 실행에서 반복하지 않았다.

## 실제 확인

1회 실제 UI 상담: 황산 96wt%와 수산화나트륨 50wt%, 20–25℃ 실외 밀폐호스 별도 이송, 사용 3형식이라는 검증용 가정을 입력했다. 혼합·동시노출 없음과 미확인 품목을 비우는 조건을 명시했다.

| 작업 구분 | 사용 형식 | 검토 보호복 | 색상 | 구성 / 남은 확인 |
|---|---:|---|---|---|
| 산 이송 | 3 | 3M 4570 | 회색 | 4품목 / 5개 |
| 알칼리 이송 | 3 | Tychem 2000 | 노랑 | 4품목 / 7개 |

HTTP 200, 응답 84.53초. DuPont 공식 원문 3개에서 두 CAS만 조회했다. 기존 저장 초안의 물질은 조회에 추가하지 않았다. 두 작업의 색은 다르지만 기존 저장 A/B의 형식·그룹이 미확인이라 사업장 전체 색상 구분은 완료됐다고 표현하지 않았다.

장화·호흡보호구는 두 조합 모두 비워 뒀다. 알칼리 보호복의 정확 스타일/국내 판매 실물·인증 연결, SSG 구판 시험의 현 제품 적용, 연결부와 실제 작업 조건 등이 남은 확인이다. 위 표는 상담 기능 검증 결과이며 실제 사용 승인이나 성능 동등성 확인이 아니다.

알칼리 선택지 1회 선택 후 JSON 보기: `selected_use_type=3`, `selected_work_group=알칼리 이송`, kit_review, 4제품 및 남은 확인 보존. `approved/runtime_registration/synthesis_created=false`. 브라우저 초안을 새로 저장하거나 A/B를 덮어쓰지 않았다. 화면은 사업장 조합의 두 선택지에 남겼다. 새로고침하면 미저장 선택지는 초기화된다.

실제 JS 함수와 카드의 가정 사례 6개 통과: 다른 형식 동색, 같은 형식·다른 작업 동색, 같은 형식·같은 작업 동색, 다른 작업 다른 색, 그룹 미상, 색상 미상. 구문/컴파일 통과, 공유 CodexClient AST·제품 catalog·live lookup 불변, 최종 서비스 ready=true. 이미지는 지연 로딩되므로 이번에 모든 화면 밖 사진의 디코딩 완료를 주장하지 않는다.
