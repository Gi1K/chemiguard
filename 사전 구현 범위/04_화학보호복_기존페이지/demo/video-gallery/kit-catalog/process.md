# 사업장 물질로 보호구 조합 만들기

기준일: 2026-10-07. [카탈로그 열기](http://127.0.0.1:34401/kit-catalog/)

회사가 사용하는 **물질·농도·작업을 먼저 입력**한다. 챗봇은 등록된 제품 자료와 제조사 물질시험표를 비교해 검토할 조합 선택지를 자동으로 제안한다. 같은 작업에 근거 있는 대안이 있으면 실제 제품 구성이 다른 2~3개를 비교한다. 한 조합만 근거가 있으면 하나만 제시하고, 물질 성분과 근거가 없으면 필요한 정보를 묻는다. 듀폰 3종은 입력 물질의 CAS로 공식 원문을 새로 조회한다. 여러 조합의 색상을 구분하려면, 보호성능과 연결 조건을 검토한 제품 중 실제 판매 색상이 다른 대안을 찾는다. 제조사는 섞을 수 있다.

## 화면에서 진행하는 순서

1. **제품 자료:** 국내 판매·견적 경로가 있는 제품을 기본으로 표시한다. 품목·모델·형식·실제 색상으로 검색하고 제품별 구매 링크, 시험 자료, 인증 확인 수준을 읽는다.
2. **물질로 추천:** 물질명 또는 CAS, 농도, 작업, 온도·시간, 비말·침수·증기 등 예상 노출을 아는 만큼 입력한다. 서로 다른 구역의 작업 목록인지, 같은 작업에서 함께 노출되는지, 실제 혼합액인지도 적는다.
3. **조합 선택지:** 챗봇이 제품 사진·이름, 다른 선택지와의 차이, 선택 이유와 남은 확인을 카드로 보여준다. 자료가 부족한 품목은 빠진 조건을 명시한 부분 조합으로 남긴다. 기존 저장 조합과 색상을 구분하는 요청도 함께 보낸다. 현재 선택지는 사업장 조합 화면에서도 비교할 수 있다.
4. **내 조합:** 원하는 카드의 ‘이 조합 선택하기’를 눌러 구성 전체를 한 번에 넣고 보호복·장갑·장화·주 호흡장비·고글·보안면을 살펴본다. 정화통·필터·홀더와 추천 근거도 함께 이어진다. 부품은 별도로 추가하거나 제거할 수 있다.
5. **초안 저장:** 여러 사업장 조합을 브라우저에 저장하고 다시 불러오거나 JSON으로 내보낸다. 물질·작업·부품을 바꾸면 이전 추천 근거를 초기화한다.

예: “A구역은 황산 30% 탱크 이송, B구역은 아세톤 용기 세척이며 서로 다른 작업입니다. 각 작업에 맞는 보호구 후보를 구성하고, 같은 보호성능의 실제 제품이 있으면 보호복 색상을 구분해 주세요.” 이 예시는 입력 방법이며 해당 작업의 승인 조합이 아니다.

## 색상은 제품 선정 다음에 결정

사업장 밖에 공통으로 적용하는 형식별 고정 색상표는 사용하지 않는다. **같은 사업장에서 서로 다른 사용 형식 또는 별도 관리 작업의 보호복 색상을 구분한다.** 같은 3형식이어도 ‘산 이송’과 ‘알칼리 세척’이 별도 작업이면 다른 색을 검토한다. 물질별 성능과 부품 연결 근거가 있는 실제 제품을 먼저 찾고, 다른 색 대안의 근거가 없으면 색상 충돌과 대안 미확인을 표시한다.

각 조합의 ‘사용 형식’은 이 작업에서 사용할 형식이다. 제품에 3·4·5·6형식이 표시돼 있어도 작업의 사용 형식을 자동으로 결정하지 않는다. ‘작업 구분’은 별도로 관리할 작업 목적의 이름이다. 같은 작업의 대체 조합은 동일한 이름을 사용한다. 추천 카드와 초안의 형식·작업 구분을 기존 저장 조합과 함께 비교하며, 둘 중 하나가 없으면 확인 전으로 남긴다. 같은 형식·같은 작업의 대체 선택지끼리는 색상이 같아도 충돌로 보지 않는다.

물질명만 다르다고 작업을 분리하지 않는다. 산과 알칼리를 함께 사용하는 작업이나 실제 혼합·중화액은 하나의 노출 조건으로 검토한다. 산용·알칼리용 조합을 따로 등록했다는 이유로 혼합액의 적합성을 확정하지 않는다. 혼합 후 조성·농도·온도와 제조사 근거가 없으면 미확인으로 남긴다. 색상은 등록 작업을 구분하는 표시이며 물질 성분을 영상으로 판단하는 기능이 아니다.

제품 사진을 다른 색으로 바꾸거나, 색상이 다른 제품을 동일 성능으로 가정하지 않는다. 정화통의 용도 표시색도 회사 구분색으로 변경하지 않는다. 색상 구분의 CCTV 인식 효과는 아직 시험하지 않았다.

## 품목별로 함께 확인할 것

| 품목 | 조합에서 확인할 조건 |
|---|---|
| 보호복 | 정확 모델의 형식, 물질·농도·온도별 투과/침투 시험, 노출 부위와 시간 |
| 화학장갑·장화 | 각 품목의 인증·물질 시험, 소매·발목 연결, 보호복 지정 부품 여부 |
| 호흡보호구 | 면체·정화통·필터·홀더의 정확 구성, 대상 가스/입자, 공기 중 농도·산소·밀착 |
| 고글·보안면 | 눈과 얼굴의 보호 범위, 비말 조건, 면체·안전모와의 간섭 |

보호복 1형식은 가스 차단, 2형식은 가스 비차단과 양압 공기공급, 3형식은 액체 차단, 4형식은 분무 차단을 구분한다. 1·2형식은 지정 공기공급·장갑·장화와 전체 시스템을 확인해야 한다. 장갑의 EN ISO 374 Type A와 장화의 성능수준은 보호복 형식 번호와 다르다. [보호구 안전인증 고시](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000232806)

면체만 선택하면 호흡 조합이 완성되지 않는다. 예를 들어 카탈로그의 3M 5P71을 6000 정화통에 결합할 때는 501이 필요하며, 2091K는 미립자용 필터로 가스·증기 정화통을 대신하지 않는다. 물리적 호환 자료와 현재 한국 인증 구성은 따로 확인한다. [3M 5P71](https://www.3m.com/3M/en_US/p/dc/v000057509/), [3M 501](https://www.3m.co.kr/3M/ko_KR/p/d/v100842470/), [3M 2091K](https://www.3m.co.kr/3M/ko_KR/p/d/v101434024/)

실제 혼합물의 적합성을 단일물질 시험 결과의 교집합으로 확정하지 않는다. 액체 농도(%)는 공기 중 노출 농도가 아니며, 시험 돌파시간도 현장 안전 사용시간이 아니다. [DuPont 선정 FAQ](https://www.dupont.com/safespec/faq.html), [Ansell 화학장갑 사용설명서](https://www.ansell.com/-/media/projects/ansell/website/pim/product-assets/ifus---chemical-products/new/ifu-chemical-resistance_split_v1-14-sv.ashx?rev=05c8ec5d3cc94984934fdce1702aa85f)

| 자료 | 수록 규모 |
|---|---:|
| 보호복 | 16종 |
| 화학장갑 / 화학장화 | 10종 / 4종 |
| 호흡장비와 부품 | 10종 |
| 고글 / 보안면 | 2종 / 2종 |
| 전체 제품 | **44종** |
| 국내 판매·견적 경로가 있는 제품 | **43종** |
| 출처 레코드 / 로컬 미리보기 이미지 | **150개 / 44제품에 사진 연결** |

국내 전체 시장의 전수 목록은 아니다. 판매 페이지가 있어도 현재 재고, 정확 판매 실물의 인증, 사업장 적합성은 별도 확인 대상이다. 국내 2형식 판매 근거는 이번 조사에서 확보하지 못했고, 해외 제조사 후보 1종은 국내 구매 필터에서 제외된다.

제품 모델·색상·판매 경로·인증 상태·시험 조건·미확인 사항을 따로 보존한다. 과거 IFU의 인증번호나 해외 Type 표기를 현재 국내 승인으로 바꾸지 않는다. 법령 자료에는 암모니아·황산·질산암모늄 세 행을 정확 전사했으며 전체 물질별 법령 매칭 엔진은 구현하지 않았다. [화학물질관리법 제14조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029307795), [개인보호장구 착용 고시](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000214471)

## 구현과 저장

```text
제품·법령·물질시험·정확 부품 연결 자료
  → 물질·농도·작업 입력
  → 같은 Codex 에이전트가 입력 번호·확실한 물질명을 CAS로 정리
  → 듀폰 공식 3제품 원단시험표를 지금 수집 / CAS 행 조회
  → 실제 조회 결과 + 등록 자료로 Codex App Server 상담
  → 근거 있는 조합 선택지 2~3개 / 한 개 / 자료 부족
  → 사진·구성 차이·선정 근거·남은 확인 비교
  → 한 번 선택해 품목·호흡부품과 근거를 내 조합에 넣기
  → 여러 초안 저장 / JSON 내보내기
```

새 물질별 대규모 규칙 엔진을 추가하지 않았다. 챗봇은 카탈로그 근거와 실제 제조사 조회 결과, 사용자의 조건으로 구조화된 후보를 작성한다. `review_draft_v4`에는 작업 설명과 작업 구분, 사용 형식, 실제 제품 ID, 복수 호흡부품, 추천 근거, 인증 스냅샷, 구매 링크를 저장한다. 이전 초안도 읽되 없는 작업 구분·사용 형식은 미확인으로 유지하고 옛 고정색 배정은 적용하지 않는다.

기존 PC의 Codex 로그인과 로컬 앱서버를 사용한다. 제품 자료는 서버 시작 때 읽으므로 자료 변경 후 `ppe-catalog-chat.service`를 재시작한다. PC와 서버가 실행 중이어야 상담할 수 있다. 대화는 새로 고침 시 초기화되고 저장한 조합은 브라우저에 남는다.

## 사진과 실시간 조회 범위

44제품 모두 로컬 미리보기 사진이 있다. 이번에 빠졌던 15종을 보완했으며, 그중 보호복 6종은 정확 판매 옵션이 확정되지 않은 제품군 대표사진으로 표시한다. 사진의 출처·모델 연결·권한은 각 제품의 `images`에 보존한다. 사진을 확보해도 현재 인증이나 합성·임베딩 이용 승인이 자동으로 확인되지는 않는다.

현재 실시간 물질 조회는 **DuPont Tychem 2000 TC198T YL, 4000 S CHZ5, 6000 F CHA6**의 한국 공식 페이지다. CAS와 물질명을 함께 입력할 수 있으며, 같은 Codex 에이전트가 요청한 물질 목록의 CAS를 먼저 정리한다. SDS 없는 미상 상품명은 추정하지 않는다. 세 페이지를 새로 받아 CAS 행과 농도·상태·온도·원본 열·각주를 함께 읽는다. 다른 제조사·장갑·장화·호흡구·법령은 기존 등록 근거를 사용한다. Lakeland 서버 접근은 403이라 실시간 연결을 완료하지 못했다.

화면의 ‘물질 조회 결과’에는 제품별·CAS별 시험 행 있음/없음/조회 실패를 구분해 표시한다. 원문 수집 시각과 시험표 개정일은 별개다. 표에 해당 CAS 행이 없으면 제조사 자료 미확보로 남기며, 적합/부적합으로 자동 판정하지 않는다. 시험 돌파시간은 현장 안전 착용시간이 아니다. 모델이 인용한 새 URL은 이번 서버가 실제 수집·해석한 제조사 URL과 일치할 때만 답변 근거로 연결한다.

## 검증과 후속 단계

자료 연결·파일 존재 검사는 [통합 확인 기록](../../../research/site_material_kits_20261006/integration_check.json)에 보존했다. 현재 상담 응답과 초안 저장의 실제 검증 결과는 [검증 기록](../../../research/site_material_kits_20261006/verification.json)에 별도로 기록한다. 자료 수록과 화면 구현은 제품 적합성 평가나 PPE 영상 인식 성능 시험을 뜻하지 않는다.

현재 범위는 후보 비교와 검토 초안이다. 회사 승인 후 착용 사진 합성·검수와 감지 DB 연결을 진행하는 후속 흐름이며 이번에 실행하지 않았다. 초안의 `approved`, `synthesis_created`, `runtime_registration`은 모두 `false`이고 사진의 임베딩·합성 이용 권한을 자동 부여하지 않는다.
