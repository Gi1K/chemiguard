## 사전 실험을 넘어서는 목표

사전 실험 결과를 그대로 서비스하는 것이 아니라 실패 조건을 비교 기준으로 삼아 본선용 최선의 검출·관찰·시간 결합 모델을 구축한다. 별도 라벨 데이터가 없으므로 이번 단계는 신규 가중치 학습이 아닌 파이프라인 개선이다. 실제 정확도가 검증되기 전에는 '최적 모델 달성'으로 발표하지 않는다.

- 사람 검출은 Medium/Large만 제공하고 Large를 초기 기본값으로 사용한다. 두 모델의 일반적 우열을 이번 소수 영상으로 확정하지 않는다.
- 첫 착의 실행에서 엄격한 단일 Pose 조건이 보조자 동반 장면의 관찰을 차단했다. 검출 대상과 Pose의 겹침으로 영역을 연결하고 연결이 불확실할 때는 사람 crop만 Decisions에 전달한다. 이 경우 제품 외형 검색은 보류한다.
- 관찰 불가 부위를 임의로 착용 처리하지 않는다. Pose 점수·입력 경로·부위 좌표계도 근거에 보존한다.
- 위반 목록 전체가 같아야 했던 시간 결합을 개선하여 연속 두 관측에서 공통으로 드러난 위반만 사건으로 올린다. 두 관측 ID를 함께 남기고 UNKNOWN·오류·만료·탐색은 연속성을 끊는다.
- 위 조건들의 수치는 검증된 현장 임계값이 아닌 개발 휴리스틱이다. 별도 촬영·라벨로 오탐, 미탐, 확인 불가 비율을 검증해야 한다.

## 추후 확장: 학습 데이터

사용자 제안 기록이며 이번 구현에 학습·자동 라벨링 파이프라인을 추가하지 않는다. 데이터 부족으로 Decisions를 활용하되 향후 자체 모델 학습을 위해 원본 시점, 대상 crop, 모델 관찰, 사람이 검수한 라벨을 구분하여 수집하는 방향을 고려한다.

현재 사건 근거와 API 원결과, 검토 이력 저장은 추적성 확보용이며 학습용 정답 데이터셋이 아니다. 사건의 '확인' 역시 모든 부위 라벨을 검수했다는 뜻이 아니다. 후속 개발에는 촬영 동의·사용 권리, 보관 기간·삭제, 개인정보 최소화, 부위별 검수와 버전, 어려운 음성 사례 수집, 촬영 그룹 단위 학습/평가 분리, 데이터셋 내보내기가 필요하다. API 응답은 pseudo-label 후보이며 정답으로 자동 승격하지 않는다.

## 검증 방침

사용자 요청에 따라 광범위한 성능 시험·반복 벤치마크를 생략한다. 빌드, 실제 GPU/Decisions 연결, 영상과 사건 검토의 짧은 동작 확인에 집중한다. 실행하지 않은 검증이나 외부 모델 품질을 완료로 기록하지 않는다. 구체 결과는 구현 후 추가한다.

실제 확인 완료: M/L GPU 추론, 착의·탈의·두 사람·작업·분출 대표 영상 5종, Decisions 호출/사건 근거, 사진 임베딩, v2 후드·여밈 질문과 전체 상태, 일시정지/탐색/재개/중지 및 늦은 응답 폐기, 검토 기록 추가와 원결과 보존, 데스크톱/모바일 렌더링. 실행 ID·수치·한계는 [개발 기록](DEVELOPMENT_LOG.md)에 누적한다. 전수 영상 평가나 독립 정확도 검증은 하지 않았다.

## CCTV 전체 구역·적응형 관찰·원본 재생 (2026-10-09)

사용자 합의: CCTV 화각 전체가 작업구역이며 착탈의 케이스도 기본 PPE 기준을 적용한다. 앞 덮개가 닫혀 지퍼를 가리는 경우 외관상 여밈 완료로 인정하되 내부 체결이나 기밀성은 주장하지 않는다. 가려진 앞면은 여전히 확인 불가다. 기존 v1/v2 정책은 유지하고 새 기본 revision을 생성한다.

이번 개선 범위는 품질/최신성 기반 짧은 근거 후보 선택, 상태별 Decisions 요청 간격(최초 즉시, 확인 1초, 미착용 지속/확인 불가 2초, 착용 유지 3초), 두 착용 관찰 후 경보 해제와 지속 위반 중복 억제, 원본 HTML video 재생과 시각 정렬된 추적 오버레이다. API 공유 대기·지연과 실제 영상 조건 때문에 요청 주기를 보장하지 않으며 영상 움직임은 착용 판정 자체가 아니다. 새 가중치 학습이나 현장 정확도 검증은 포함하지 않는다.

추가 동기화 보정: 편집 영상의 장면 전환을 PySceneDetect로 찾아 추적/대상 연결을 초기화하고, 실제 표시 프레임의 mediaTime으로 박스와 사람별 관찰을 함께 정렬한다. 로컬 처리 5Hz와 원본 재생 FPS는 분리되며, 장면 경계에서는 보간하거나 과거 박스를 유지하지 않는다.

## 보이는 범위 착용 관찰 (2026-10-09)

사용자 승인 후 기본 정책 v4에 `visible_regions` 관찰을 추가했다. 필수 몸통·양팔·양다리·후드·앞 여밈을 없애지 않고 현재 화각의 관찰과 전체 항목 관찰을 구분한다. 몸통과 최소 한 팔다리의 착용 근거가 있으며, 보이는 부위의 위반·판독 불확실이 없으면 `VISIBLE_WORN`이다. 안 보이는 부위는 미확인으로 남는다. 전 항목을 관찰한 `WORN`도 보호 성능·안전 인증은 아니다.

Luna 질문은 안 보임/판독 불확실을 구분하고 margin 0.2 미만은 uncertain으로 처리한다. 새 가중치·새 AI 제공자는 추가하지 않는다. 사람별 연속 두 번의 착용 관찰 뒤 영상 위 라벨은 사용자 요청대로 '착용', 상세는 '보이는 범위 착용'과 미확인 항목이다. 기존 위반이 미해제이면 경보가 우선하며 해당 부위의 covered/closed를 두 번 확인해야 항목별로 해제한다. 원응답·상태 전환·해제 근거를 기록한다.

기존 정책/실행은 보존한다. 새 정책 설정과 관제·영상 라벨·사건 근거가 이번 본선 개선이며, 기존 영상/가중치는 여전히 사전 준비물이다. 실제 확인과 잔여 한계는 개발 기록에 별도로 남긴다.

## 전면형 방독면 필수 관찰 (2026-10-09)

사용자는 안면보호구 종류를 전면형 방독면으로 확정했다. 새 기본 정책의 `respirator_required`와 독립 `respirator` 질문을 추가하고, 사람별 부위 표시·위반 요약·연속 경보·해제 근거에 연결한다. 사람 전체 영상과 기존 머리 상세를 함께 참고하며 후드 옵션과 별도로 머리 입력을 전달한다. 전면형 대신 반면형+보안경 또는 페이스실드를 자동 인정하지 않는다.

보이는 얼굴의 미착용은 위반에 포함한다. 안 보이는 얼굴은 not_visible, 장비 유형·착용을 구분하기 어려우면 uncertain이다. 관찰 가능한 부위의 착용 라벨과 전체 필수 부위 관찰을 계속 구분한다. 외관상 착용만 다루며 필터 적합성·밀착도·보호 성능 판정은 제외한다. 이전 정책과 실행 기록, Medium/Large·Luna 및 원본 영상은 보존한다.

## 현장 대표 제품 등록·실제 외형 비교 (2026-10-09)

사용자 최신 방향에 따라 용도·형식별 대표 보호복 하나와 색상을 등록/수정/비활성화하는 관리 기능을 추가했다. 색상·용도 매핑은 아직 미정이므로 실제 등록 목록은 비어 있다. 등록 이력은 append-only revision이며 실행 시작 때 활성 목록을 고정해 SigLIP2 비교 대상을 제한한다. 이는 영상 관제용 등록 관리이며 별도 보호복 검색/상담 카탈로그의 구현이 아니다.

새 Pose 몸통 맥락 crop, 제품 사진만의 유사도 순위, 실제 입력/가장 유사한 사진·점수·시각, 제조사 자료·내산/내염기 시험 조건, 종료 후 저장된 비교 조회를 본선에 추가했다. 정확 SKU는 미확정으로 두고 계열 후보까지만 표시한다. 참고 자료로 기존 로컬 제품 사진 6장과 사전 SigLIP2/Pose 가중치를 사용했으며 사진·가중치를 본선 신규 제작으로 기록하지 않는다.

현재 색상은 현장 등록 설명이며 별도 자동 색상 분류는 없다. 등록 전에는 참고 제품 사진 비교임을 구분한다. 한 후보만 등록해도 자동 일치 확정하지 않는다. 두 사람 영상에서 실제 새 추론·표시는 동작했지만 비슷한 흰색 계열의 구분 실패가 남아 있다. 색상이 구분되는 실제 현장 제품의 정확도, 신규 학습, 작업 물질별 보호 적합성·안전 착용시간 판정은 완료 범위가 아니다.

(1) Pose 얼굴 키포인트와 턱/방독면 여유 영역을 이용한 head crop, 몸통 부위 추정 실패 시에도 연결된 머리 맥락 유지, (2) head 원본 픽셀의 PNG 무손실 인코딩과 나머지 PPE crop JPEG 95, (3) 최근 0.8초 내 동일 대상/시점 후보의 얼굴 품질·최신성 선택과 Pose 결과 재사용, (4) gpt-6-luna Decisions의 detail=original 및 입력별 포맷/크기/해시 기록이다. 선택된 동일 프레임에서 사람/모든 부위 근거를 구성한다.

사용자 최신 합의로 서버가 첫 WORN/VISIBLE_WORN 응답을 두 번째 관찰 전까지 UNKNOWN으로 숨기던 표시 조건을 제거했다. 영상 박스·사람별 관찰·지정 보호구 상단 집계가 첫 유효 결과부터 반영된다. 등록 제품 결과는 별도로 필요하며 보이는 범위 착용과 전체 필수 부위 관찰을 구분한다.

confirmed와 complete_confirmed는 2회 연속 근거를 뜻하는 기존 의미로 유지한다. 단일 현재 관찰은 연속 2회라고 표시하지 않는다. 첫 미착용 라벨, 같은 부위 2회 경보, 해당 부위 2회 직접 복구와 미해제 경보 우선은 변경하지 않는다. API/모델·입력·필수 착용 기준은 그대로이며 API 응답·재생 정렬 지연은 남는다.


## 시연 시작 명칭 (2026-10-09)

관제 시작 버튼과 영상 하단 접근성 안내를 '시연 시작'으로 통일하고 완료 후 안내는 '시연 다시 시작'으로 바꿨다. 문구만 변경했으며 감지·재생·경보 동작은 동일하다.
